Шахматы с другом — это минималистичное Android-приложение для игры в шахматы вдвоем. Быстрая регистрация, простой интерфейс и возможность сразу начать игру с другом делают его идеальным выбором для любителей шахмат. Приложение разработано на Java в Android Studio с использованием SQLite для локального хранения данных и Firebase для онлайн-игры. Архитектура MVVP и кастомный View обеспечивают чистоту кода и удобство разработки.

📱 Основные функции
- Быстрая регистрация ⚡: начните игру за несколько секунд.
- Игра с другом 👥: пригласите друга и начните партию.
- Минималистичный дизайн 🎨: лаконичный и понятный интерфейс.
- Оффлайн-режим 📴: играйте локально, используя SQLite.
- Онлайн-режим 🌐: играйте с другом через Firebase.
- Кастомный View 🖌️: уникальная доска и фигуры, созданные с нуля.

🛠️ Технологии и инструменты
Языки и фреймворки

- Java ☕
- Android SDK 📱

Базы данных

  - SQLite 💾 (для локального хранения данных)

- Firebase 🔥 (для онлайн-игры и синхронизации)

Архитектура

  - MVVP (Model-View-ViewModel) 🧩

Дизайн

  - Кастомный View 🎨 (шахматная доска и фигуры)

  - Material Design 🖌️ (минималистичный интерфейс)

🧩 Архитектура приложения

Приложение построено на архитектуре MVVP:

  - Model: Отвечает за данные (SQLite, Firebase).

   - View: Отображает интерфейс (кастомный View для шахматной доски).

   - ViewModel: Связывает Model и View, обрабатывает логику игры.
